プライバシーポリシー

アカシロラボ YouTube UploadにおけるGoogleユーザーデータと制作関連情報の取扱いを説明します。

制定日：2026年10月28日

1. 対象と目的

本ポリシーは管理者向けツール「アカシロラボ YouTube Upload」（以下「本アプリ」）に適用されます。本アプリは本人のYouTubeチャンネルの制作、投稿支援、分析、Google Driveとのファイル連携に利用します。一般ユーザー向けアカウント登録サービスは提供していません。

2. アクセスするデータと権限

  • YouTube Data API：管理対象のチャンネル・動画情報、公開状態、再生数等の取得、管理者が承認した動画のアップロード
  • YouTube Analytics API / Reporting API：視聴時間、視聴維持率、インプレッション、CTR、流入元などの分析情報
  • Google Drive API：管理者の動画素材、脚本、品質検査記録、分析資料などの取得・保存・更新
  • OAuth認可情報：Googleから発行されるアクセス・更新トークン等。Googleパスワードは取得しません

3. データの利用目的

  • 管理対象の動画を確認し、管理者承認に基づく投稿を支援するため
  • 視聴データを分析し、企画、演出、タイトル、サムネイル等の改善に役立てるため
  • Google Driveと制作環境の間で制作・分析ファイルを連携するため
  • 認証、通信障害、欠測、品質検査等の状態を確認するため

本アプリはYouTube API Servicesを利用しています。Googleプライバシーポリシーもご参照ください。

4. データの保存場所と取扱い

データおよび認可情報は、管理者が管理するPC、Google Drive、または管理者が認めた処理環境で保存・処理される場合があります。認証情報を公開サイトや公開リポジトリには掲載しません。管理者が指定するAIサービスや制作・分析ツールに、必要な範囲の情報を処理させる場合があります。

5. 第三者提供と外部サービス

Google、YouTube、Google Drive、管理者が承認した外部ツール等、必要なサービスを利用します。Googleユーザーデータを広告配信や販売の目的で第三者へ提供しません。サイト自体に独自の追跡Cookieや広告タグは設置していません。ホスティング事業者が保有するアクセスログ等については、当該事業者のポリシーに従います。

6. 保管・更新・削除

データは目的に必要な範囲で保持し、GoogleとYouTubeの適用APIポリシーに従って更新・削除します。認可の取消しや削除依頼があった場合は、対象となる保存データと認可情報を確認し、適用されるポリシーに従って削除します。アプリ側の保存データの削除は、YouTubeに投稿済みの動画自体を削除するものではありません。

7. アクセス権の取り消し

Googleアカウントの接続管理から本アプリのアクセス権を取り消せます。保存データの削除は下記連絡先にお問い合わせください。

GitHub Issuesは公開されます。問い合わせには個人情報、認証トークン、秘密情報を書き込まないでください。個別のデータ削除については、公開Issueで連絡手段のみご相談ください。

8. 安全管理

トークンなどの秘密情報を公開サイトに掲載せず、管理者が許可した環境で管理します。APIアクセス、認証、ファイル連携に関する安全管理を必要に応じて見直します。

9. 改定

APIやアクセス権、処理方法が変更された場合、本ポリシーを更新し、重要な変更について必要に応じて通知・同意取得を行います。
